TASK 9: Preventing Prescription Fraud
Problem: Digital prescriptions can be altered by patients for drug abuse or insurance fraud. Pharmacists need to verify authenticity.
1. Digital Signatures (RSA 2048-bit)
Implement digital signatures using RSA 2048-bit private keys for doctors to cryptographically sign prescriptions.
Priority: MEDIUM | Effort: 4 days | Assignee: Security Team
Implementation Steps:
Generate RSA key pair for each doctor on registration
Private key: Encrypted with doctor's password, stored in database
Public key: Stored in Prescription table
When doctor creates prescription → Sign with private key: signature = RSA.sign(prescription_data, private_key)
Store signature in Prescription.digital_signature field
Pharmacist verifies: valid = RSA.verify(prescription_data, signature, public_key)
If verification fails → Show alert: '⚠️ Prescription may be tampered. Call doctor to confirm.'
Prescription PDF includes QR code with signature (pharmacist scans to verify)
2. Audit Trail & Government Verification
Log every edit with timestamp, user ID, IP address. Integrate CoWIN-style government verification system for pharmacists.
Priority: MEDIUM | Effort: 3 days | Assignee: Backend Team
Implementation Steps:
AuditLog table: {action, entity_type, entity_id, user_id, ip_address, timestamp, changes_json}
Log all CRUD operations on Prescription, PharmacyOrder, PatientProfile
Example: {action: 'UPDATE', entity_type: 'Prescription', entity_id: 'abc123', user_id: 'doc456', ip: '192.168.1.1', timestamp: '2026-05-01 10:30', changes: '{medication: Aspirin → Clopidogrel}'}
Admin dashboard: View audit trail (filter by user, date, entity)
Government verification (future): Integrate with ABDM (Ayushman Bharat Digital Health Mission)
Pharmacist scans prescription QR code → API call to ABDM: 'Is this prescription authentic?'
ABDM returns: {valid: true, doctor_license: 'MH12345', issued_at: '2026-05-01'}
